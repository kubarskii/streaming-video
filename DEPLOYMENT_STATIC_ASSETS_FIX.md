# Исправление 403 Forbidden для статических файлов в продакшене

## Проблема
Статические файлы (JS, CSS) возвращают 403 Forbidden в развернутом приложении.

## Внесенные исправления

### 1. Пропуск auth middleware для статических файлов
- Статические файлы теперь пропускают auth middleware
- Это предотвращает 403 ошибки на `/assets/*.js`, CSS, изображения и т.д.

### 2. Исправление Dockerfile
- Исправлено копирование файлов из `dist` в `public`
- Теперь копируются содержимое `dist/*` в `public/`, а не сама папка `dist`
- Добавлены правильные права доступа (755)

### 3. Улучшенная обработка ошибок
- Добавлена проверка безопасности путей
- Добавлено логирование для отладки

## Дополнительные проверки для продакшена

### 1. Проверьте логи при старте
После деплоя проверьте логи - вы должны увидеть:
```
📁 PUBLIC_DIR: /app/public
📁 PUBLIC_DIR exists: true
📁 Assets directory exists: true
📁 Sample assets: react-vendor-*.js, ...
```

### 2. Проверьте структуру файлов в контейнере
Если проблема сохраняется, проверьте структуру:
```bash
# В контейнере или через Railway CLI
ls -la /app/public/
ls -la /app/public/assets/
```

Файлы должны быть в `/app/public/assets/react-vendor-*.js`, а не в `/app/public/dist/assets/`

### 3. Проверьте reverse proxy (если используется)
Если используется nginx или другой reverse proxy, убедитесь что:
- Статические файлы не блокируются правилами
- Правильные headers для CORS
- Правильные пути проксирования

Пример конфигурации nginx:
```nginx
location /assets/ {
    proxy_pass http://localhost:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    add_header Cache-Control "public, max-age=31536000";
}
```

### 4. Проверьте права доступа
В Dockerfile файлы должны иметь права 755:
```bash
chmod -R 755 /app/public
```

### 5. Проверьте переменные окружения
Убедитесь что `NODE_ENV=production` установлен правильно.

### 6. Пересоберите и перезапустите
```bash
# Пересоберите образ
docker build -t your-app .

# Или если используете Railway/другой сервис
# Просто сделайте новый деплой
```

## Отладка

Если проблема сохраняется, проверьте логи сервера при запросе:
```
⚠️  Static file not found: /assets/react-vendor-Bzgz95E1.js (resolved: /app/public/assets/react-vendor-Bzgz95E1.js)
```

Это покажет:
- Какой путь запрашивается
- Куда он разрешается
- Существует ли файл

## Возможные причины 403 в продакшене

1. **Reverse proxy блокирует** - проверьте конфигурацию nginx/Apache
2. **Файлы не скопированы** - проверьте что `dist/*` скопированы в `public/`
3. **Неправильные права** - файлы должны быть читаемыми (755)
4. **Путь разрешения** - файлы должны быть в `/app/public/assets/`, не в `/app/public/dist/assets/`
5. **CDN/Cloudflare** - если используется CDN, проверьте его настройки

## Тестирование

После деплоя проверьте:
```bash
curl -I https://your-domain.com/assets/react-vendor-Bzgz95E1.js
```

Должен вернуть `200 OK`, а не `403 Forbidden`.
